# Student Management System

A simple Python command-line project to manage student records.

## Description

Student Management System is a beginner-friendly Python project that allows users to add, view, search, update, and delete student details using a menu-based interface. The project stores student records temporarily in a Python list while the program is running.

## Features

- Add student details
- View all students
- Search student by ID
- Update student details
- Delete student record
- Exit the program

## Student Details Stored

Each student record contains:

- Student ID
- Name
- Age
- Mark

## Technologies Used

## Concepts Used

- Lists
- Dictionaries
- Loops
- Conditional statements
- User input
- CRUD operations
